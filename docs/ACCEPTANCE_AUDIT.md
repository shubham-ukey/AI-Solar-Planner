## Known SRS conflicts and scope gaps

1. AC-04 expects Maps Places Autocomplete. The lazy-loaded UI now implements it, but the service wrapper is only a boundary helper and live key testing remains pending. Manual entry is the fallback, not a substitute for the complete acceptance criterion.
2. AC-12 says “Subsidy page”; the UI presents the subsidy source and verification status in the results and assumptions screens, not a separate route.
3. Subsidy values satisfy the confirmed SRS test examples but are marked unverified. Formula conformance does not establish current scheme accuracy.
4. Phase 5 FAQ count remains the confirmed 4–5 AI FAQ rule, while the SRS says 5–8; fallback proposal FAQs can contain five. No change was made in Phase 8.
5. The SRS asks for an admin-protected Firestore data layer, while public lead intake needs a server-side endpoint to write leads under admin-only Firestore rules. This remains a production integration requirement.
